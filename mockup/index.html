web-player

A private management console and a password-protected public web player for the files and links on your Synology NAS — with Enigma2 bouquets for the satellite box.

INTERACTIVE MOCK-UP fake data · nothing is written to the NAS

🛠

Management console

Private. Media library, users, per-user playlists, outputs, bouquets.
  • Add local files, URLs and YouTube links
  • Enable/disable each item per user
  • Pick the output: web player and/or Enigma2
  • Preview and push the bouquet file
▶

Public web player

Password protected. The playlist of the signed-in user only.
  • Search the playlist
  • Play, pause, skip, fullscreen
  • Jump to any timestamp
  • Resume where you left off
